# Inequity and Ecosystem Functioning project

This repository contains code and data to reproduce the analyses from the Inequity and Ecosystem Functioning project.

The aim of the project is to integrate the ideas and methods from economics (Gini-coefficient) and the North American breeding bird survey data to test the consequences of the population declines on ecosystem functioning and evenness.

## Data

The raw data is retrived from the North American Breeding Bird Survey:

Pardieck, K.L., Ziolkowski Jr., D.J., Lutmerding, M., Aponte, V.I., and Hudson, M-A.R., 2020, North American Breeding Bird Survey Dataset 1966 - 2019: U.S. Geological Survey data release, https://doi.org/10.5066/P9J6QUF6.

## Code

R Code which was used to perform the analyses and figures are provided. Scripts commencing with BBS can be used to redo the analysis (Calculate the Gini coefficient and Energyflux). Figures can also be plotted using the results_BBS_complete.csv dataframe containing the results, as the analysis is very time-consuming.

# BirdInequity

R code for the manuscript **"Energetic stability despite 58 years of population declines in North American bird communities"**

**Daria Lipsky, Lina K. Mühlbauer, Jose W. Valdez, Henrique M. Pereira, Jes Hines**

[![DOI](https://zenodo.org/badge/DOI/ADD-ZENODO-DOI-HERE.svg)](https://doi.org/ADD-ZENODO-DOI-HERE)

---

## Overview

This repository contains the R code used to process data, fit models, and produce all figures and statistical tables for the manuscript. We use 58 years of standardised breeding bird count data (1966–2023) from the North American Breeding Bird Survey to track how species richness, abundance, community unevenness (Gini coefficient), and community-level energy demand have co-changed over time and across dietary functional guilds.

## Data

The raw data are public and are not redistributed here unless the licence of the original source allows it. Please download them from the original sources and cite them.

### Breeding Bird Survey (BBS)

Download the BBS dataset from the USGS ScienceBase repository:

> Ziolkowski, D., Lutmerding, M., English, W. B., & Hudson, M.-A. R. (2024). *North American Breeding Bird Survey Dataset (1966–2023)*. U.S. Geological Survey. https://doi.org/10.5066/P136CRBV

Place the state-level count files in `data_2025/States/`, then uncomment the three-line block at the top of Section 2 in `01_gini_bbs_clean.R` to combine them into `States_combined_2025.csv`. The remaining files (`Routes.csv`, `SpeciesList.csv`, `Weather.csv`) are included in the BBS download.

### EltonTraits 1.0

Download the bird functional trait database from:

> Wilman, H., et al. (2014). EltonTraits 1.0: Species-level foraging attributes of the world's birds and mammals. *Ecology*, 95, 2027. https://doi.org/10.1890/13-1917.1

Place `BirdFuncDat.csv` in the `Elton1.0/` directory.

## Requirements

- R 4.5.0 or later
- R packages: `lme4` (mixed-effects models), `MuMIn` (R²), `DescTools` (Gini coefficient), `ggplot2` and `patchwork` (figures). The scripts may load further packages (for example for data handling); check the `library()` calls at the top of each script.

Install the main packages with:

```r
install.packages(c("lme4", "MuMIn", "DescTools", "ggplot2", "patchwork"))
```

---

## How to run

1. Download the data as described above and place the files in the folders shown in the repository structure.
2. Set the working directory to the repository root (for example by opening the project folder in RStudio).
3. Run `01_gini_bbs_clean.R` once. It creates `data_2025/RouteMetrics_2025_diet.csv`.
4. Run `figure_1.R` to `figure_4.R` in any order. The figures are written to `figures/`.
